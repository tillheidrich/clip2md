# iPhone shortcut for clip2md

iOS does not let web apps into the share sheet. This Shortcut copies the current Safari page and opens clip2md.

1. Open **Shortcuts**, tap **+**, name it **clip2md**.
2. Tap **ⓘ**, enable **Show in Share Sheet**, allow **Safari web pages**, **Rich text**, **Text**.
3. Add **Get Details of Safari Web Page** → **Page Contents** (input: Shortcut Input).
4. Add **Copy to Clipboard**.
5. Add **Open URLs** → `https://clip2md.heidrich-digital.de/?from=ios` (use your own domain when self-hosting).

In Safari: Share → **clip2md** → tap **Paste**. iOS asks once whether clip2md may paste.

For a selection only, no Shortcut is needed: copy it and use the Paste button.

## Deutsch

1. App **Kurzbefehle** öffnen, **+** tippen, Name **clip2md**.
2. **ⓘ** tippen, **Im Share-Sheet anzeigen** einschalten, **Safari-Webseiten**, **Rich Text**, **Text** zulassen.
3. Aktion **Details von Safari-Webseite abrufen** → **Seiteninhalt**.
4. Aktion **In Zwischenablage kopieren**.
5. Aktion **URLs öffnen** → `https://clip2md.heidrich-digital.de/?from=ios`

In Safari: Teilen → **clip2md** → **Einfügen** tippen.
